# Spy killer

## ⚠️ WARNING for Apple Software Users (Adobe, iCloud, etc.)

This script includes a cleanup of the `adobegc.log` file, which is generated by **Adobe Genuine Software Integrity Service**.

If you use **Adobe software on Windows** (such as Photoshop, Premiere Pro, After Effects, etc.), especially in conjunction with **Apple cloud services** (like iCloud syncing or cross-platform project workflows), you **should NOT run this script without understanding the impact**.

Deleting `adobegc.log` may:
- Trigger Adobe’s license revalidation
- Break cloud sync or launch behavior
- Cause instability in Creative Cloud tools (especially on managed Apple-linked accounts)

➡️ In short: **Do NOT use this script if you're relying on Apple/Adobe cross-platform tools on Windows.**


---

## 🔥 What is Spy Killer?

Spy Killer is a focused, no-BS PowerShell script to:

- **Disable hidden telemetry**
- **Remove Cortana + OneDrive**
- **Clean AdobeGC spyware logs**
- **Kill bloatware apps**
- ...while keeping your Xbox/Game Bar & Microsoft gaming services **intact**.

Built for **power users who care about privacy and performance**.

---

## ✅ Features

| Category      | Action                                                                 |
|---------------|------------------------------------------------------------------------|
| Telemetry     | Disables DiagTrack, Push, MapsBroker, Media Sharing                   |
| Cortana       | Uninstalled (AppX + Provisioned package)                              |
| OneDrive      | Uninstalled system-wide (cleanly)                                      |
| Bing Search   | Disabled in Registry (HKCU)                                            |
| Indexing      | ✅ Preserved (you can still search your apps instantly)                |
| AdobeGC       | Deletes `adobegc.log` spyware file                                     |
| Bloatware     | Removes GetHelp, Skype, 3DViewer, Zune, etc. (**excludes Xbox apps**)  |

---

## 📦 Requirements

- Windows 10 or 11 (Pro, Home, Enterprise — NOT Windows S)
- PowerShell 5.1+  
- Admin privileges (the script will auto-elevate)

---

## 🚀 How to Use

1. Download the script: [`SpyKiller.ps1`](./SpyKiller.ps1)
2. Right click → **Run with PowerShell (Administrator)**  
   OR:
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\SpyKiller.ps1
````

3. Let it clean. Reboot your machine.

Spy Killer **frees your system** without breaking the tools gamers need.
